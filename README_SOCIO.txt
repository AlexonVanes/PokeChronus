README PARA USAR O PROJETO

1. Instale o Git for Windows.
2. Instale o Git LFS se ele nao vier junto com o Git.
3. Clone o repositorio em uma pasta do computador.
4. Abra VERIFICAR_AMBIENTE.bat.
5. Antes de mexer em qualquer coisa, abra ATUALIZAR.bat.
6. Para abrir o servidor, use INICIAR_SERVIDOR.bat.
7. Para abrir o client, use INICIAR_CLIENT.bat.
8. Depois que terminar suas alteracoes, abra ENVIAR.bat.
9. Se aparecer conflito ou erro, chame o Alexon.
10. Nao mexa ao mesmo tempo que outra pessoa em arquivos grandes como:
   - Tibia.spr
   - Tibia.dat
   - Tibia.cwm
   - map.otbm
   - items.otb

Regra simples:
Sempre abra ATUALIZAR.bat antes de comecar.
Sempre abra ENVIAR.bat quando terminar.
